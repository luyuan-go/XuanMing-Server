## 2. 画像结论（定谳）

### 2.1 CPU — 战斗窗口 365s，GameThread 忙 320s ≈ 0.88 核（占全进程 93%，其余 15 线程合计 <8%）

| 排名 | 系统 | 占忙时 | 证据（窗口内累计） |
|---|---|---|---|
| 1 | 怪物 CharacterMovement | **~38%** | 2.61M 次移动组件 tick（139/帧）；`ComputeFloorDist` **独占 48.8s=15%**；GeomSweepSingle/Multiple 共 5.3M 次 91s；`ResolvePenetration` 19.8 万次 27.2s |
| 2 | Tick 调度机器 | ~14% | 11.2M 个 FTickFunctionTask（598 个/帧）；QueueTicks 16.3s + ResetTickGroup 10.5s + ProcessUntilTasksComplete 11.9s 均为纯调度 |
| 3 | 网络复制 | ~11% | ServerReplicateActors 33.9s；1.64M 次 actor 复制、5.87M 次属性比较——仅 1 个连接 |
| 4 | Chaos 物理 | ~9% | 主要是 150 角色的 kinematic 更新（AdvanceOneTimeStep 14.4s 等） |
| 5 | RHI/渲染残迹 | ~1.9%（修正值） | 调用树单链 `Render_EndFrame→RHICmdList_Submit→RHITaskPipe→GPUProfiler::ProcessEvents`，不重叠合计 ~6s；早期 3-4% 是嵌套重复相加的高估 |
| 6 | GAS | ~2% | 84.4 万次 ASC tick 6.1s（NPC ASC 复制模式已是 Minimal，无需改） |

### 2.2 内存 — LLM 标签归属

- 空载 361MB，8 分钟曲线纹丝不动，**无泄漏**。
- 战斗 RSS 1.16~1.31GiB（真实堆 FMalloc 785MB；LLM 采集自身开销 ~146MB 已含）。
- 增量几乎全部是 **Physics 家族 ~558MB**：ChaosAcceleration 164 + ChaosGeometry 122 + ChaosUpdate 68 + ChaosBody 51 + ChaosActor 45 + StaticParticles 38 + Trimesh 20；其余系统全部个位数 MB。战斗图加载时一次性跳上去，之后平稳。
- 14Gi limit 对实际 1.3GiB 严重超配，可灰度降 4Gi（K8s 配置，另行拍板）。

### 2.3 停摆炸弹 — NoFOW（空载会话铁证）

- `/Game/LayeredFOW_Edit/MiniMapSystem/NoFow/BP_NoFOW_Minimap` 在 DS 上每帧 `GetPlayerPawn→GetPlayerCameraManager→MinimapWidget` 三连 Accessed None + 整份脚本栈转储；空载忙时占 21%、日志占 14%（均值 354 条/s、峰值 851 条/s）。
- 抓到一次 **2.65 秒整世界停摆**，调用链逐帧可循：`TG_PrePhysics → FTickFunctionTask → BP_NoFOW_Minimap.ReceiveTick → ExecuteUbergraph → STAT_FMsgLogf 2.6503s`（日志写线程反压，同 hub DS 卡死同源）。
- 战斗窗口它本体仅 0.9s——罪在停摆风险与日志，不在均值。

### 2.4 根因链 — 怪物卡岩石（三个症状一个病）

1. **navmesh 与物理世界不一致**：PCG 摆的岩石 ISM（`ISM_SM_Rock_Flake/Cliff_Rock/Rock_Boulder`、`BPP_Rock_Arctic_PageRock`）有阻挡碰撞；组件 `bCanEverAffectNavigation` 为默认 true（uasset 无覆盖串），但**烘焙 navmesh 未刻入岩石**（最可能：摆完没重烘）→ 选路穿岩石 → 水平 sweep 被真实碰撞挡住 → 永远到不了路点，每帧穿透解算。
2. **出生点静默回退**：`ResolveSpawnLocation` 在 `GetRandomReachablePointInRadius` 失败（WP 服务器流送下导航分块未就绪）时回退裸 SpawnCenter 硬塞，`AdjustIfPossibleButAlwaysSpawn` 对 trimesh 解不开 → 怪永久嵌入。
3. **碰撞复杂度**：ScifiArctic 63 个网格 `CTF_UseComplexAsSimple`（含 SM_Cliff_Rock 全系/Medium_Rock/Rock_Wall/Pillar/Plate/Mesa/Cave_Hexa/Volcanic 等）——角色扫掠直接怼原始三角网格，`ComputeFloorDist` 的 15% 与 Physics 内存 558MB 同源。
- 引擎事实（5.8 源码核实）：NavWalking 治「扫地贵」不治「卡岩石」（`PhysNavWalking` 仍走 `SafeMoveUpdatedComponent(bSweepWhileNavWalking)` 水平扫掠）；`SetGroundMovementMode(MOVE_NavWalking)` 保证击飞进 Falling 落地后自动回落；投影不到 nav 时 StartFalling/退 Walking 有兜底。**顺序必须是先修数据再切模式**。
