# Triage Labels

这些 skills 使用五种标准分流角色。下表把标准角色映射到本仓库问题跟踪器中的实际标签。

| mattpocock/skills 标签 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此问题 |
| `needs-info` | `needs-info` | 正在等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给无人值守 Agent |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某种角色（例如“应用可交给 AFK Agent 的标签”）时，使用表中对应的实际标签字符串。

如果仓库已有不同的标签词汇，只需修改右侧“本仓库标签”列。
